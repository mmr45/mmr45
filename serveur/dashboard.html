    Comment ça marche

    Ce compteur mesure les chargements de la carte « visites », pas des personnes uniques. Le proxy d’images de GitHub peut garder une image en cache, et les rechargements peuvent compter plusieurs fois. Ce serveur ne reçoit pas l’identité du visiteur GitHub : il conserve l’heure du chargement et la variante claire ou sombre de l’image. Le total inclut un ancien compteur ; les graphiques commencent à la date de début du suivi détaillé. Pour les coups de pinceau, seul le pays peut apparaître publiquement. L’actualisation se met en pause quand cet onglet est masqué.
