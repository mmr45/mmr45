    Comment ça marche

    Chaque fois que quelqu’un ouvre le profil, GitHub charge la carte « visites » depuis ce serveur : c’est ce chargement qui est compté, en direct. GitHub cache volontairement l’identité des visiteurs (les images passent par son proxy), donc personne, ni moi ni GitHub, ne peut savoir qui regarde un profil. Ce tableau ne garde que l’heure de chaque visite et le thème clair ou sombre du navigateur. Pour les peintres du mur, seul le pays est retenu.
