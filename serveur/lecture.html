COMMENT JE CONSTRUIS

Du premier fichier à la mise en ligne

Je développe des interfaces en JavaScript et TypeScript. Selon le projet, j’utilise Vue, Tailwind, HTML et CSS. Node.js, Supabase et PostgreSQL assurent les fonctions serveur, les comptes et les données. Vercel héberge les applications ; Stripe gère les paiements. Certaines fonctionnalités utilisent l’IA.

Git et GitHub suivent les modifications. Le code est proposé par pull request avant sa validation et la publication sur la branche de production.
